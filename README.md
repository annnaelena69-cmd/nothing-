# NoahDroid 😂

**INI CUMA TROLL.** Aplikasi iseng untuk hiburan, bukan aplikasi sistem atau keamanan. Aplikasi hanya menampilkan penghitung tombol dan tombol reset. Aplikasi ini tidak mengakses akun, pesan, foto, lokasi, atau data pribadi.

## Fitur
- Tampilan gelap sederhana
- Penghitung tombol dan tombol reset
- Mendukung Android 6.0 (API 23) ke atas
- Build APK otomatis melalui GitHub Actions

## Unduh untuk Android
1. Buka [hasil build terbaru di GitHub Actions](https://github.com/annnaelena69-cmd/nothing-/actions).
2. Pilih proses **Build Android APK** terbaru yang bertanda centang hijau.
3. Pada halaman proses tersebut, cari bagian **Artifacts** dan ketuk `NoahDroid-debug-apk` untuk mengunduh ZIP.
4. Ekstrak ZIP di HP, lalu ketuk `app-debug.apk` untuk memasang.
5. Jika diminta, izinkan pemasangan dari sumber tersebut untuk browser atau aplikasi file yang digunakan.

Artifact GitHub Actions adalah unduhan build sementara dan dapat kedaluwarsa. APK ini merupakan build debug untuk pengujian, bukan aplikasi yang dipublikasikan di Google Play. Jangan pasang aplikasi dari sumber yang tidak dipercaya.

## Build APK
Workflow **Build Android APK** berjalan otomatis setiap ada push ke branch `main`. Bisa juga dijalankan manual melalui **Actions** → **Build Android APK** → **Run workflow**.
