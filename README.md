# NoahDroid

Proyek Android native sederhana berbasis Kotlin.

## Fitur
- Tampilan gelap sederhana
- Tombol penghitung
- Tombol reset
- GitHub Actions untuk membangun APK debug secara otomatis

## Build APK
Buka tab **Actions**, jalankan workflow **Build Android APK** lewat **Run workflow**, lalu unduh artifact `NoahDroid-debug-apk` setelah proses selesai.
