# NoahDroid 😂

**THIS IS JUST A TROLL APP.** It is made for fun and entertainment. The app only displays a button counter and a reset button. It does not access accounts, messages, photos, location, or personal data.

## Features
- Simple dark interface
- Button counter and reset button
- Supports Android 6.0 (API 23) and later
- Automatic APK builds with GitHub Actions

## How to Download and Install on Android
1. Open the [GitHub Actions page](https://github.com/annnaelena69-cmd/nothing-/actions).
2. Select the latest **Build Android APK** run with a green check mark.
3. On the run page, scroll to **Artifacts** and tap `NoahDroid-debug-apk` to download the ZIP file.
4. Open your phone's Files app or file manager and extract the downloaded ZIP.
5. Find `app-debug.apk` in the extracted folder and tap it.
6. If Android asks for permission, allow your browser or file manager to install apps from this source.
7. Return to the installer and tap **Install**.
8. When installation finishes, tap **Open** to launch NoahDroid.

## Important Notes
- Only install APK files from sources you trust.
- This is a debug APK for testing and is not published on Google Play.
- GitHub Actions artifacts are temporary downloads and may expire.
- If installation fails, check that the latest build completed successfully. Android may also prevent installation if a different-signed version of NoahDroid is already installed.

## Build the APK
The **Build Android APK** workflow runs automatically whenever changes are pushed to the `main` branch. You can also run it manually from **Actions** → **Build Android APK** → **Run workflow**.
